Kjerag

Native 360° video player for the COSMIC desktop. Open an Insta360 .insv straight off the camera and press play.

Install Kjerag

Or add the repository and install by name:

flatpak remote-add --if-not-exists kjerag https://kjerag.harding.dev/kjerag.flatpakrepo
flatpak install kjerag dev.harding.Kjerag

Builds are signed. Source, issues and releases live on GitHub.
